V in the browser

V, compiled to WebAssembly, runs on this page and its output is built and run here too. Nothing is sent to a server.

Loading V compiler…
Runs the whole toolchain on the page, in a worker, through @live-codes/v-wasm: the V compiler takes your program to C against the full standard library, then Clang and LLD — also WebAssembly — build that C and run it. The compiler assets (~31 MB) and the C toolchain (~29 MB) are served from this repository and downloaded on first use.
